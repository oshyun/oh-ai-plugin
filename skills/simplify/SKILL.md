# Simplify (코드 정제)

이 스킬은 코드 작성/수정 후 커밋 전에 호출되어야 한다. 다음 4가지 관점(R.S.E.A)에서 현재까지 작업한 변경사항(diff)을 검토하고 사소하지 않은 문제가 있다면 코드를 수정한다.

1. **Reuse (재사용성)**: 기존에 존재하는 유틸리티, 헬퍼 함수, 컴포넌트, 혹은 디자인 패턴을 다시 만들지 않았는가?
2. **Simplification (단순화)**: 요청된 범위를 넘어서는 투기적 추상화나 불필요한 로직이 포함되지 않았는가? 코드는 당장의 문제를 해결하는 가장 단순한 형태인가?
3. **Efficiency (효율성)**: 불필요한 반복문, 불필요한 마이그레이션 등 명백한 성능 오버헤드나 불필요한 런타임 의존성을 발생시키는 코드가 없는가?
4. **Altitude (아키텍처 부합성)**: 이 변경이 기존 시스템의 일관성을 해치지 않고 전체 구조적 관점에서 자연스럽게 녹아드는가?

검토 결과 수정이 필요하다면 사용자에게 알리고 즉시 코드를 수정한다.
문제가 없다면 스킬을 완료하고 다음 단계(code-review 등)로 넘어간다.
