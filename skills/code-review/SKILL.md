# Code Review (최종 코드 리뷰)

이 스킬은 `simplify` 완료 후 커밋 직전에 호출된다. 아래 체크리스트를 기반으로 작성된 코드를 비판적으로 리뷰한다.

1. **명명 규칙 (Naming)**:
   - 새 식별자(변수, 함수, 클래스 등)가 `data`, `value`, `flag`, `info`, `result` 등 모호한 이름이 아닌 즉시 이해 가능한 풀어쓴 이름인가?
   - 새로 작성한 코드나 주석에 의미가 불명확한 약어가 포함되지 않았는가?
2. **단일 출처 (SSOT)**:
   - 같은 속성이나 설정값이 여러 곳에 복사되어 중복 관리되고 있지 않은가?
3. **엣지 케이스 및 예외 처리**:
   - 널(null) 참조, 잘못된 타입 입력 등의 상황이 적절히 방어되었는가?
4. **주석 및 태그 시스템**:
   - 기술 부채(REFAC), 알려진 버그(FIXME), 하위 호환(COMPAT), 라이브러리 우회(QUIRK) 코드가 있다면 공통 포맷(`이유 줄 + 제거 조건 줄`)에 맞게 작성되었는가?

수정해야 할 부분이 발견되면 즉시 코드를 수정하고, 모든 문제가 해결되면 리뷰를 마친다.
